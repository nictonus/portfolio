# Hardware Engineering & Repair Portfolio

Welcome to my professional portfolio. This repository documents a comprehensive log of hardware diagnostics, micro-soldering, modular replacements, and preventative maintenance across enterprise and consumer electronics.

## 📁 Repository Structure

*   **`repairs/`**: Detailed, photographically documented case studies categorized by repair type (cleaning, headphones, keyboards, phones, soldering, water damage). Each case includes high-resolution teardown images and detailed technical reports.
*   **`video/`**: Compressed video logs demonstrating complex teardowns, structural restorations, and logic board replacements on enterprise hardware (Lenovo, Dell, HP) and wearables.
*   **`pdf/`**: Official OEM service qualification certificates (Dell, HP) and academic programming credentials (C++, Python, JavaScript).
*   **`REPAIR_LOG.csv`**: A master database of 1700+ documented hardware tickets, detailing reported issues, diagnostic event feeds, and completed works. This file is natively interactive within GitHub.

## 🛠️ Core Competencies

*   **Component-Level Repair:** Micro-soldering, BGA rework, trace repair, and liquid damage restoration on densely packed logic boards.
*   **Modular Overhauls:** OEM-compliant teardown and reassembly of enterprise laptops, gaming chassis, and sealed wearables.
*   **Diagnostics & QA:** Advanced thermal management (liquid metal, PCM phase transition), power delivery validation, and structural integrity restoration.
